# Mac-sized bitmap to 286 EGA comparison — 2026-11-14

The paired-release goal needs reproducible comparisons of a 512x342 monochrome scene across Mac and 286 presentation paths. `scripts/compare_mac_pc286.py` accepts a caller-provided original/rights-cleared binary PBM of exactly that size. It constructs an original floppy diagnostic that loads the complete 21,888-byte bitmap through three track-bounded BIOS reads into 286 RAM, selects the BootHush EGA profile, and copies the inverted monochrome bits to the unscaled canvas at `(64,4)`. It then compares each of the 175,104 canvas pixels and all 48,896 margin pixels with the PBM-derived expected RGB image. PBM bit 1 denotes black; the tested EGA model's white plane bits are its inversion. It refuses an invalid PBM before creating an output directory and checks that its original floppy is unchanged.

The focused regression includes a mathematically generated original bitmap with changing rows and byte-boundary patterns, plus a truncated-input refusal. The broader 286 test also covers keyboard-controlled original frame motion; [that receipt](pc286-keyboard-drag-20261114.md) identifies its separate test-source snapshot. No emulator implementation was used as an implementation input for this black-box script.
