# Original 286 EGA and keyboard probe — 2026-11-14

The next ClasSICK pair targets Mac128K and PC/AT 286, so this original BootHush black-box fixture asks whether the documented PC profile can display an unscaled 512x342 bitmap at `(64,4)` in 640x350 and deliver keyboard direction events to a small 16-bit guest. This is an independently authored diagnostic boot sector and geometric image, not ClasSICK code, Apple code, a window, an installed OS, or a hardware test. It depends on BootHush's built-in BIOS shim and EGA model, not an IBM firmware image.

`tests/test_pc286_pair_canvas.py` creates a 1.2 MiB original read-only floppy, sets EGA mode 10h and fills the canvas. An original cursor variant inverts one 8-pixel row and uses BIOS keyboard calls to move it right and left. It reads the guest's retained cursor offset and move count at `0x600`, compares all 224,000 RGB pixels including margins and restored background, and checks the input disk hash is unchanged. Scheduled set-2 right make is at cycle 2,000,000, right break at 2,100,000/2,101,000, and left make at 3,000,000. The right and left runs are independent cold boots, not a live human test.

On BootHush executable SHA-256 `1f306c427d1a8c42b9d547b2b25a424e4b4e6a389a52ae5861d030e0fe43bc25`, all three tests passed. With cursor-fixture SHA-256 `1c0a2a6b2514d72791b5d681deba2b3b3b6f9bed4f0835816a264f37ce73f460`, POST `a2` stopped at modeled cycle 2,000,061 with memory `611f0100`; POST `a3` stopped at cycle 3,000,080 with `601f0200`. The cursor was at framebuffer `(264,100)` and `(256,100)` respectively, with the prior position restored. The 8-pixel step and cursor glyph are diagnostic choices.
